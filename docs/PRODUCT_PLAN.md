# StudyCheck 商业化产品执行 Plan

> 执行规则：以后所有编码优先服务本 Plan；完成一个 Gate 才进入下一个 Gate。禁止为了“看起来完整”提前扩展无关基础设施。

## 产品定位
面向中国学生与家庭的低门槛 AI 学习助手。核心价值：把教材、笔记和错题转成可执行的学习任务、练习与复习反馈，降低整理成本并提高复习效率。

## 技术路线
- Python 作为核心业务语言
- 保留现有领域层，优先模块化单体
- HTTP 层保持可适配 FastAPI
- SQLite 用于 MVP；达到规模后迁移 PostgreSQL
- LLM 通过 Provider 接口接入，不锁定单一模型
- 学习算法、题目生成、资料解析、报告均可独立测试

## 严格执行的 6 个阶段

### P1 核心学习闭环
- PDF/DOCX/文本资料解析
- 知识点抽取
- 学习计划
- 每日练习
- 答题与判定
- 错题记录
- 掌握度更新
- 间隔复习队列
**Gate：真实资料可完成一次完整学习循环。**

### P2 AI + 学习算法
- LLM Provider
- 题目生成与质量校验
- 难度控制
- 解析与知识点绑定
- 间隔复习/遗忘曲线策略
- 生成结果防幻觉与引用证据
**Gate：题目、答案和解析可追溯到资料或明确标记为生成内容。**

### P3 商业级 Web/API
- FastAPI adapter
- 登录/租户/权限
- 资料、计划、练习、错题 API
- 任务状态与错误规范
- 最小可售卖前端工作流
**Gate：新用户无需开发者介入即可完成学习流程。**

### P4 收费与成本控制
- 免费额度
- 学生低价 Pro
- Usage 计量
- 支付 Provider
- 订单幂等
- 超额限制
- AI 成本监控
**Gate：付费后权益和额度正确生效。**

### P5 生产化
- PostgreSQL 迁移路径
- 对象存储适配
- 异步任务
- Docker
- 日志、健康检查、错误追踪
- 文件隔离、限流、安全审计
- E2E 回归
**Gate：可部署、可恢复、可观测。**

### P6 商业 MVP
- Landing Page
- 新手引导
- 示例课程/资料
- 帮助文档
- 隐私/服务条款占位
- 核心漏斗埋点
- 上线检查清单
**Gate：陌生学生可注册、导入资料、完成学习、试用并进入付费路径。**

P1 / 核心学习闭环。
